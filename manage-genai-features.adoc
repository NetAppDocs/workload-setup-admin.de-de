= KI-Funktionen in NetApp Workload Factory verwalten
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Zugriff auf KI-Funktionen in Workload Factory steuern. Sie können KI-Funktionen deaktivieren oder AWS Bedrock verwenden, das von NetApp oder Ihrem Unternehmen verwaltet wird.



[[about-ai-features]]
== Über KI-Funktionen

Workload Factory umfasst mehrere KI-gestützte Funktionen, die Ihre Benutzererfahrung verbessern, wie z. B. Ask Me, KI-Agenten, benutzerdefinierte Dashboards, Rule Errichter und Analysetools für EMS, Datenbankprotokolle und Latenz.

Als Administrator von Workload Factory kann auf der Seite „KI-Einstellungen“ gesteuert werden, wie diese Funktionen KI nutzen.



[[configuration-options]]
== Konfigurationsoptionen

Wählen Sie aus diesen Konfigurationsoptionen:

NetApp Managed Bedrock (Empfohlen):: Ein von NetApp verwalteter AWS Bedrock Service kann verwendet werden. Diese Option wird für die meisten Benutzer empfohlen.
+
--
* Ihre Daten werden nicht zum Trainieren von Modellen verwendet
* Monatliche Nutzungsguthaben sind organisationsweit gemeinsam nutzbar.
* Keine zusätzliche AWS-Einrichtung ist erforderlich.


--
Vom Kunden verwaltetes Bedrock:: Ihre eigene AWS Bedrock Konfiguration wird verwendet.
+
--
* Für optimale Ergebnisse empfiehlt NetApp die Verwendung von Anthropic Claude Sonnet 4.5 oder 4.6 mit Ihrer Amazon Bedrock Konfiguration.


--
GenAI Funktionen deaktiviert:: Alle KI-Funktionen werden deaktiviert. Benutzer können „Ask Me“, den KI-Agenten, Analysetools, benutzerdefinierte Dashboards, den Regel-Errichter oder andere KI-gestützte Tools nicht mehr verwenden.




[[before-you-begin]]
== Bevor Sie beginnen

* Es wird empfohlen, dass ein Kontoadministrator die KI-Funktionen einrichtet.
* Wenn Sie kundenverwaltetes Bedrock verwenden, ist eine Aktualisierung der AWS-Richtlinie für die mit der Workload Factory IAM-Rolle verknüpften Anmeldeinformationen erforderlich.



NOTE: Die AWS-Richtlinie muss um die erforderlichen Berechtigungen für die Anmeldeinformationen ergänzt werden, die mit der Workload Factory IAM-Rolle verknüpft sind.



[[configure-ai-features]]
== KI-Funktionen konfigurieren

.Schritte
. Melden Sie sich mit einem der link:console-experiences.html["Konsolenerfahrungen"^] an.
. Im Menü erfolgt die Auswahl von *Administration* > *Einstellungen* > *KI-Tools*.
. Auf der Seite *AI tools* erfolgt die Auswahl der bevorzugten Konfiguration:
+
** *NetApp-verwaltetes Bedrock (Empfohlen)*: NetApp-verwaltetes AWS Bedrock verwenden.
** *Kundenseitig verwaltetes Bedrock*:
+
... Auswahl der AWS-Anmeldeinformationen und der Region, die der Workload Factory IAM-Rolle zugeordnet sind
... Das Inferenzprofil angeben, das Sie verwenden möchten
... *Konfiguration validieren* auswählen.
+
Workload Factory zeigt eine Benachrichtigung an, die angibt, ob die Verbindung erfolgreich war oder fehlgeschlagen ist



** *GenAI Funktionen deaktiviert*: Alle KI-Funktionen sind ausgeschaltet.


. Wählen Sie *Änderungen speichern*.


.Ergebnis
Ihre Einstellungen werden gespeichert und sofort auf alle KI-Funktionen in Workload Factory angewendet. Im Tracker ist ersichtlich, wer die Einstellungen zuletzt aktualisiert hat und wann.

Wenn KI-Funktionen deaktiviert sind, sehen Nutzer eine Meldung, wenn sie versuchen, KI-gestützte Funktionen zu verwenden. Die Benutzeroberfläche bleibt sichtbar und zeigt deutlich, dass die Funktion nicht verfügbar ist.



[[budget-controls-and-credit-limits]]
== Budgetkontrolle und Kreditlimits

NetApp verwaltet Budgetkontrollen für KI-Funktionen nur dann, wenn Sie die standardmäßige, von NetApp verwaltete Konfiguration verwenden.



[[monthly-credit-limits]]
=== Monatliche Kreditlimits

Jedes Konto hat ein monatliches Ausgabenlimit für jede KI-Funktion, wenn NetApp-verwaltetes Bedrock verwendet wird.



[[when-budget-is-reached]]
=== Wenn das Budget erreicht ist

Wenn Ihr Konto das monatliche Budgetlimit erreicht, führt Workload Factory Folgendes aus:

* KI-Funktionen deaktivieren und die zugehörigen Teile der Benutzeroberfläche ausgrauen
* Diese Meldung als Tooltip anzeigen: „Monatliches KI-Guthaben erreicht. Wenden Sie sich an den NetApp Support.“
* Protokollnutzung zu Nachverfolgungszwecken




[[request-additional-credits]]
=== Zusätzliche Gutschriften beantragen

Falls Sie mehr KI-Guthaben benötigen, wenden Sie sich an Ihren NetApp Ansprechpartner. Ihr Ansprechpartner kann das Kreditlimit entsprechend Ihres Bedarfs anpassen.

[TIP]
====
Um Ihren NetApp Ansprechpartner bezüglich Kreditlimits zu kontaktieren, kann der In-Product-Chat genutzt werden oder die link:get-help.html["Holen Sie sich Hilfe"] Seite aufgerufen werden.

====


[[govcloud-considerations]]
== GovCloud Überlegungen

Wenn ein Workload Factory Konto in AWS GovCloud (US) erstellt wird, ist zu beachten, dass KI-Funktionen standardmäßig AWS Bedrock Dienste in öffentlichen AWS Regionen verwenden.

Wenn Ihre Sicherheitsanforderungen keine Verbindungen zu öffentlichen AWS Region Services zulassen, können KI-Funktionen deaktiviert werden.

link:sign-up-saas.html["Informationen zur Erstellung von GovCloud-Konten"].



[[impact-on-existing-sessions]]
== Auswirkungen auf bestehende Sitzungen

Wenn Sie die KI-Einstellungen ändern, werden alle aktiven KI-Sitzungen sanft beendet. Laufende Arbeitsabläufe können abgeschlossen werden, aber neue Anfragen verwenden die aktualisierten Einstellungen.

Das Beendigungsverhalten kann je nach Funktion variieren. Einzelheiten sind in der funktionsspezifischen Dokumentation zu finden.
