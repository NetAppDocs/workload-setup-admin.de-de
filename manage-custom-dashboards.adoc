= Benutzerdefinierte Dashboards verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Verwalten Sie Ihre benutzerdefinierten Dashboards im Dashboard-Katalog. Von dort aus lassen sich Details anzeigen, Dashboards freigeben, Daten aktualisieren oder Dashboards, die nicht mehr benötigt werden, löschen.

.Über diese Aufgabe
Im Dashboard-Katalog können benutzerdefinierte Dashboards angezeigt und verwaltet werden. Private Dashboards sind nur für Sie sichtbar, während öffentliche Dashboards für alle Benutzer Ihres Workload Factory Kontos sichtbar sind. Jedes Dashboard zeigt grundlegende Details wie den Namen des Erstellers, das Erstellungsdatum und eine Kennzeichnung der Sichtbarkeit (Privat oder Öffentlich).

Benutzerdefinierte Dashboards sind schreibgeschützt. Sie können weder Ihre Speicher- noch Ihre Workload-Einstellungen ändern.

.Bevor Sie beginnen
Sie müssen mindestens ein benutzerdefiniertes Dashboard in Ihrem Workload Factory Konto haben.



[[access-the-dashboard-catalog]]
== Auf den Dashboard Katalog zugreifen

.Schritte
. Melden Sie sich mit einem der link:console-experiences.html["Konsolenerfahrungen"^] an.
. Im Menü *Workloads Overview* und anschließend *Custom dashboards* auswählen.
+
Der Dashboard Katalog zeigt alle benutzerdefinierten Dashboards in Ihrem Workload Factory Konto an.

. Die Dashboard-Liste wird angezeigt.




[[change-dashboard-visibility]]
== Dashboard-Sichtbarkeit ändern

Ein Dashboard kann öffentlich gemacht werden, um es mit dem Team zu teilen. Durch das Setzen auf privat wird die gemeinsame Nutzung beendet.

.Schritte
. Auf der Seite *Benutzerdefinierte Dashboards* das Dashboard suchen, das aktualisiert werden soll.
. Im Dropdown-Menü *Aktionen* image:icon-action.png["Das Drei-Punkte-Symbol, das das Aktionsmenü öffnet"] für dieses Dashboard eine der folgenden Optionen auswählen:
+
** *Dashboard teilen* – Macht das Dashboard für alle Benutzer Ihres Workload Factory Kontos sichtbar.
** *Auf privates Dashboard umschalten* – macht das Dashboard nur für Sie sichtbar




.Ergebnis
Das Dashboard wird sofort aktualisiert. Die Sichtbarkeitsanzeige auf der Dashboard-Karte zeigt den aktuellen Status.



[[refresh-dashboard-data]]
== Dashboard-Daten aktualisieren

Dashboard-Daten werden beim Öffnen eines Dashboards geladen. Eine Aktualisierung zeigt die neuesten Informationen an.

Das Dashboard lädt Daten aus Ihren Workloads neu. Die Zeitangabe „Letzte Aktualisierung“ ändert sich und zeigt an, wann die Daten aktualisiert wurden.



[[delete-a-dashboard]]
== Ein Dashboard löschen

Dashboards, die nicht mehr benötigt werden, können gelöscht werden. Dieser Vorgang ist endgültig und kann nicht rückgängig gemacht werden.

.Schritte
. Auf der Seite *Benutzerdefinierte Dashboards* das Dashboard suchen, das entfernt werden soll.
. Im Dropdown-Menü *Aktionen* für dieses Dashboard die Option *Löschen* auswählen.
. Bestätigen Sie die Löschung.


.Ergebnis
Das Dashboard wird dauerhaft aus Ihrem Workload Factory-Konto entfernt und alle Benutzer verlieren den Zugriff darauf.
