= Benutzerdefinierte Dashboards in NetApp Workload Factory verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Verwalten Sie Ihre benutzerdefinierten Dashboards im Dashboard-Katalog. Von dort aus lassen sich Details anzeigen, Dashboards freigeben, Daten aktualisieren oder Dashboards, die nicht mehr benötigt werden, löschen.

.Über diese Aufgabe
Im Dashboard-Katalog lassen sich benutzerdefinierte Dashboards anzeigen und managen. Private Dashboards sind nur für Sie sichtbar, während öffentliche Dashboards für alle Benutzer in Ihrem Workload Factory Konto sichtbar sind. Jedes Dashboard zeigt grundlegende Details wie den Namen des Erstellers, das Erstellungsdatum und eine Transparenzkennzeichnung (Privat oder Öffentlich).

Benutzerdefinierte Dashboards sind schreibgeschützt. Sie können weder Ihre Speicher- noch Ihre Workload-Einstellungen ändern.

.Bevor Sie beginnen
Sie müssen mindestens ein benutzerdefiniertes Dashboard in Ihrem Workload Factory Konto haben.



[[access-the-dashboard-catalog]]
== Auf den Dashboard Katalog zugreifen

.Schritte
. Melden Sie sich mit einem der link:console-experiences.html["Konsolenerfahrungen"^] an.
. Im Menü *Workloads Overview* und anschließend *Custom dashboards* auswählen.
+
Der Dashboard Katalog zeigt alle benutzerdefinierten Dashboards in Ihrem Workload Factory Konto an.

. Die Dashboard-Liste wird angezeigt.




[[change-dashboard-visibility]]
== Dashboard-Sichtbarkeit ändern

Ein Dashboard kann öffentlich gemacht werden, um es mit dem Team zu teilen. Durch das Setzen auf privat wird die gemeinsame Nutzung beendet.

.Schritte
. Auf der Seite *Benutzerdefinierte Dashboards* das Dashboard suchen, das aktualisiert werden soll.
. Im Dropdown-Menü *Aktionen* image:icon-action.png["Das Drei-Punkte-Symbol, das das Aktionsmenü öffnet"] für dieses Dashboard eine der folgenden Optionen auswählen:
+
** *Dashboard teilen* – Macht das Dashboard für alle Benutzer Ihres Workload Factory Kontos sichtbar.
** *Auf privates Dashboard umschalten* – macht das Dashboard nur für Sie sichtbar




.Ergebnis
Das Dashboard wird sofort aktualisiert. Die Sichtbarkeitsanzeige auf der Dashboard-Karte zeigt den aktuellen Status.



[[refresh-dashboard-data]]
== Dashboard-Daten aktualisieren

Sie können prüfen, wann Ihr Dashboard zuletzt aktualisiert wurde, und bei Bedarf einen Scan auf Abruf anfordern, wenn aktuelle Daten benötigt werden.

.Über diese Aufgabe
Der Tooltip „Daten aktualisieren“ zeigt einen Zeitstempel „Zuletzt aktualisiert“ mit dem Datum und der Uhrzeit an, zu denen das Dashboard zuletzt aktualisiert wurde. Dieser Zeitstempel bezieht sich auf die erfassten Daten, nicht auf den Zeitpunkt der letzten Änderung der Dashboard-Konfiguration.

Die Auswahl von *Daten aktualisieren* startet einen neuen Scan. Während ein Scan läuft, ist die Schaltfläche deaktiviert, und die zugehörige QuickInfo zeigt an, dass ein Scan im Gange ist.

Workload Factory protokolliert ein Ereignis in Tracker, wenn Sie entweder *Daten aktualisieren* oder *Jetzt laden* auswählen. link:monitor-operations.html["Informationen zur Überwachung von Vorgängen mit Tracker"].

.Schritte
. Im Dashboard-Katalog können Sie das Dashboard öffnen, das Sie anzeigen möchten.
. Durch Bewegen des Mauszeigers über *Daten aktualisieren* können Sie Datum und Uhrzeit der *Letzten Aktualisierung* prüfen.
. Aktualisierte Metriken lassen sich über *Daten aktualisieren* anfordern.
+
Ein Banner signalisiert den Start eines Scans. Es ist erforderlich, den Abschluss des Scans abzuwarten.

. Wenn neue Daten verfügbar sind, wird in einem Banner folgende Meldung angezeigt: „Neue Daten sind verfügbar. Sie können sie jetzt laden oder jederzeit auf „Daten aktualisieren“ klicken, um die Ansicht zu aktualisieren.“
. Im Banner steht *Jetzt laden* zur Verfügung, um die verfügbaren Daten in das Dashboard zu laden. Alternativ steht *Daten aktualisieren* zur Verfügung, um die Ansicht zu aktualisieren.


.Ergebnis
Das Dashboard zeigt die aktualisierten Kennzahlen an.



[[edit-dashboards]]
== Dashboards bearbeiten

Sie können ein Dashboard bearbeiten, um zu ändern, was es anzeigt, einschließlich der Kennzahlen, Diagramme und Zeitbereiche.


NOTE: Nur der Ersteller des Dashboards kann das Dashboard bearbeiten. Während der Bearbeitung sind Ihre Änderungen für andere Nutzer erst sichtbar, nachdem Sie sie gespeichert haben.

.Schritte
. Auf der Seite *Benutzerdefinierte Dashboards* das Dashboard suchen, das bearbeitet werden soll.
. Im Menü *Aktionen* für dieses Dashboard die Option *Dashboard bearbeiten* auswählen.
. Im KI-Dialog die gewünschten Änderungen beschreiben.
+
Dieser Vorgang ähnelt dem Erstellen eines neuen Dashboards. Die Workloads, Metriken oder Zeiträume, die das Dashboard erfasst, können geändert werden.

. Die Änderungen überprüfen und **Speichern** auswählen.


.Ergebnis
Das Dashboard wird mit Ihren Änderungen aktualisiert. Das Datum der letzten Änderung wird ebenfalls aktualisiert.



[[delete-a-dashboard]]
== Ein Dashboard löschen

Dashboards, die nicht mehr benötigt werden, können gelöscht werden. Dieser Vorgang ist endgültig und kann nicht rückgängig gemacht werden.

.Schritte
. Auf der Seite *Benutzerdefinierte Dashboards* das Dashboard suchen, das entfernt werden soll.
. Im Dropdown-Menü *Aktionen* für dieses Dashboard die Option *Löschen* auswählen.
. Bestätigen Sie die Löschung.


.Ergebnis
Das Dashboard wird dauerhaft aus Ihrem Workload Factory-Konto entfernt und alle Benutzer verlieren den Zugriff darauf.
